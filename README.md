# Rekap E-GOTO

Website rekap bulanan anggota tim E-GOTO.

## Anggota
- Ernest
- Arief
- Dilla
- Fauzan
- Fikri

## Fitur
- Pilih bulan rekap
- Tabel terpisah untuk setiap anggota
- Nomor baris otomatis
- Status: Belum, Proses, Tertunda, Selesai
- Tambah dan hapus baris
- Penyimpanan lokal di browser (localStorage)
- Export / Save as PDF
- Responsive untuk mobile, tablet, laptop, dan desktop
- Warna identitas berbeda untuk setiap anggota

## GitHub Pages
Gunakan `index.html` sebagai halaman utama.

Setelah file ada di branch `main`:
1. Buka **Settings**
2. Pilih **Pages**
3. Pada **Build and deployment**, pilih **Deploy from a branch**
4. Pilih branch **main**
5. Pilih folder **/(root)**
6. Klik **Save**

Alamat Pages akan menjadi:
`https://fikrialv.github.io/Rekap-e-goto/`

> Catatan: data rekap tersimpan di `localStorage` browser/perangkat. Data tidak otomatis sinkron antar perangkat.
